一、产品概述
1.1 产品定位
本产品为多人登录式个人博客系统，支持多用户独立注册、登录，每个用户拥有专属博客空间，可自主发布、编辑、删除博客内容，浏览其他用户博客，实现个人内容分享与简单交互，暂无管理员权限（本期不涉及用户管理、内容审核等管理员操作，二期做）。
1.2 核心目标
1. 支持多用户独立账号体系，实现安全登录、退出、个人信息管理
2. 为每个用户提供专属博客空间，支持博客全流程操作（发布、编辑、删除、预览）
3. 实现用户间博客浏览、简单互动（评论、点赞、转发）
4. 保证系统操作流畅、逻辑清晰，降低用户使用门槛
1.3 适用用户
所有需要个人博客空间、用于分享内容（文章、图片等）的普通用户，支持多用户使用，各用户数据独立隔离
1.4 产品边界
1. 本期不涉及管理员账号及相关操作（无用户管理、内容审核、系统配置等操作）
2. 用户仅能操作自身账号及博客内容，无法干预其他用户数据
3. 不涉及功能付费、广告植入、第三方登录（可预留扩展位）
二、用户角色与权限
1. 游客
- 浏览系统首页所有公开博客列表，单篇博客详情
- 查看所有用户的公开个人主页（仅展示公开信息）
- 搜索公开博客（按标题）
- 不可进行发布、编辑、评论、点赞等操作，不可查看非公开内容
2. 普通登录用户
- 账号管理：登录、退出、忘记密码、修改/查看个人信息（昵称、头像、密码等）
- 自身博客管理：发布、编辑、删除、预览自身博客，查看自身博客列表和详情
- 互动操作：对其他用户公开博客进行评论、点赞
- 基础操作：浏览所有公开博客、搜索博客、查看其他用户公开主页
三、业务流程图
1. 用户注册 -> 登录
2. 用户登录 -> 忘记密码(通过邮箱验证找回密码)
3. 所有人查看公开博客列表/详情/搜索博客（按博客标题模糊搜素）
4. 所有人可查看所有用户的公开个人主页
5. 登录用户查看自身博客列表/详情/发布/编辑/删除/预览博客
6. 登录用户对所有博客可评论/点赞
7. 登录用户可退出登录
8. 登录用户可查看/修改个人信息
四、功能需求
4.1 账号注册
- 昵称：必填，4-20 位，字母开头，字母 / 数字 / 下划线
- 邮箱：必填，用于找回密码，邮箱符合邮箱格式
- 密码：必填，8-20 位，字母 + 数字
- 校验规则：昵称唯一，邮箱唯一
- 异常处理：用户名重复、密码不一致、格式错误等，给出明确提示，允许用户重新输入；
4.2 账号登录
- 昵称：必填；
- 密码： 必填；
- 校验规则：用户名存在、密码与用户名匹配；
- 异常处理：用户名不存在、密码错误，给出明确提示；连续输错10次锁定账号；
- 状态保持：登录成功后，系统自动保存登录状态（Cookie），登录有效期为2天
4.3 账号退出
- 通过Cookie获取用户信息和登录态，然后登出账号，非登录不能退出
4.4 忘记密码
- 邮箱：必填，邮箱符合邮箱格式
- 验证码： 必填
- 密码：必填，8-20 位，字母 + 数字
- 异常处理：邮箱不存在，给出明确提示
4.5 设置-资料与头像设置
- 头像：非必填，支持png/jpg
- 昵称： 必填，4-20 位，字母开头，字母 / 数字 / 下划线
- 个人简介：必填，8-50 位
- 手机号：非必填，如果有符合手机号格式
- 校验规则：手机号如果有要唯一，登录态用户客户修改设置，非登录不能修改
4.6 设置-邮箱与密码
- 邮箱：必填，邮箱符合邮箱格式
- 当前密码： 必填，4-20 位，字母开头，字母 / 数字 / 下划线
- 新密码：必填，4-20 位，字母开头，字母 / 数字 / 下划线
- 校验规则：邮箱唯一，非登录不能修改
4.7 设置-注销账号
- 通过Cookie获取用户信息和登录态，然后登出账号
- 校验规则：邮箱唯一，非登录不能注销
4.8 上传头像功能
- 通过文件流上传
- 支持png/jpg/jpeg格式
- 上传的文件重新名（命名规则：时间加当前上传的递增个数，并加上user_logo前缀）
- 上传的文件在当前服务中新增user_logo_images文件夹，并将图片存储在该文件夹中，并返回新的图片url
4.9 新建博客文章
- 标题：必填，4-30字
- 可见范围：必填，枚举值：公开：open；仅自己可见：only_myself
- 文章分类：必填，枚举值：后端：‘1’；前端：‘2’；Android：‘3’；iOS：‘4’；人工智能：‘5’；工具开发：‘6’；阅读：‘7’
- 正文：必填，富文本字符串，最多能存5000字
- 校验规则：同一用户标题唯一，非登录不能新建
4.10 编辑博客文章
- 标题：必填，4-30字
- 可见范围：必填，枚举值：公开：open；仅自己可见：only_myself
- 正文：必填，富文本字符串，最多能存5000字
- 校验规则：非登录不能编辑
4.11 查看我的博客文章列表
- 返回字段：标题，状态（中文），更新时间
- 支持按博客名称模糊查询
- 校验规则：非登录不能查看，分页查询，默认每页十条，支持传参拓展
4.12 查看文章详情
- 返回字段：标题，更新时间，博客正文，博客分类，点赞数量
- 校验规则：非登录不能查看
4.13 查看当前文章的评论列表
- 返回字段：评论人昵称，评论人头像，评论更新时间，评论内容
- 校验规则：非登录不能查看
4.14 发表评论提交
- 提交内容字段：必填，1-300字
- 校验规则：禁止出现侮辱，攻击性语言，非登录不能提交
4.15 删除评论
- 校验规则：非登录不能删除
4.16 删除单条我的博客文章
- 校验规则：根据文章id删除，非登录不能删除
4.17 给博客文章点赞
- 校验规则：非登录不能点赞
4.18 给博客文章取消点赞
- 校验规则：非登录不能取消点赞
4.17 获取用户信息
- 返回字段包括：用户昵称，用户邮箱，用户头像，用户个人简介，用户手机号
- 校验规则：非登录不能获取
4.18 查看公开博客列表
- 返回字段包括：标题，用户昵称，博客类型，更新时间，点赞数量，评论数量，博客中文
- 校验规则：不需要登录即可查看，分页，默认每页十条，列表按照博客分类进行查询；支持通过博客标题模糊查询；
4.19 查看当前登录用户公开博客列表
- 展示个人信息：标题，博客类型，更新时间，博客中文
- 校验规则：非登录不可查看，分页，默认每页十条
